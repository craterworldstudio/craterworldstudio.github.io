# Soulfire · Crater World

Personal developer portfolio and cybersecurity project platform for **Soulfire**, an independent software developer and aspiring cybersecurity student.

## Core Features

- **Restored Signature Hero**: The original welcome banner (`/images/Welcome page.png`) and studio ethos: *"Keep Things Fast, convenient and safe!"*
- **Solo Developer Profile**: Highlights focus areas across application security, network scanning, defensive scripting, and full-stack software development.
- **Projects**: Dedicated project catalog for cybersecurity tools, network utilities, and applications with detailed specs and inspect modals.
- **News & Devlogs**: Technical study notes, security lab breakdowns, and milestone posts formatted with zero-pill typography.
- **Feedback & Contact**: Direct message and feedback submission channel with client-side persistence and history tracking.

## Technology Stack

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Lucide React
